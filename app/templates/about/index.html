{{ _('What is WhatSend?') }}

{{ _("WhatSend lets you schedule messages to be sent immediately or at a specific time — one-time or recurring. It supports WhatsApp (via Whapi.Cloud) and Signal (via signal-cli REST API). You create a job with a message, pick a recipient, and choose a trigger — the app handles the rest.") }}

{{ _('The story') }}

{{ _("Originally named WhatSend, this project was born out of a simple problem: we had a place where WhatsApp messages needed to be sent for events on specific days, but we'd often forget or be late.") }}

{{ _("v1 was a Python script using pywhatkit to send messages automatically. It worked — kinda. But it required a browser with an already signed-in WhatsApp user, was painfully slow, and couldn't run on a server.") }}

{{ _("We went back to manual sending for a while. Then v2 appeared: same idea but powered by the Whapi.Cloud API instead of pywhatkit. A huge improvement — no browser needed, fast, server-ready.") }}

{{ _("But it was still configured via a YAML file, which meant editing files and redeploying every time something changed. So v3 added REST APIs so everything could be configured remotely. Then the question came: how will normal people use this? That's when the web dashboard was born — Jinja2 templates, HTMX for interactivity, zero JavaScript build step.") }}

{{ _("And that's where we are today. WhatSend is a full-featured WhatsApp scheduler you can deploy on a $5/month server and control from any browser.") }}

{{ _('Getting an API token') }}

{{ _('WhatsApp (Whapi.Cloud)') }}

  1. {{ _('Go to whapi.cloud and sign up.') }}
  2. {{ _('Create a new channel and link your WhatsApp account by scanning the QR code.') }}
  3. {{ _('Copy your API token from the channel dashboard.') }}

{{ _('Signal (REST API)') }}

  1. {{ _('Run a signal-cli-rest-api Docker container (e.g. bbernhard/signal-cli-rest-api).') }}
  2. {{ _('Register your Signal number with the API.') }}
  3. {{ _('Configure the SIGNAL_BASE_URL and SIGNAL_NUMBER in your environment.') }}
{{ _('Note:') }} {{ _("API tokens are encrypted at rest using Fernet symmetric encryption.") }}
